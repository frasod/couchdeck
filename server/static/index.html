Your launchers

Grok

Grok reads Claude’s project instructions on its own. A CLAUDE.md in the repo, .claude/CLAUDE.md, the same names under ~/.claude/, and markdown in .claude/rules/ and ~/.claude/rules/ are loaded as rules. It also picks up Claude skills, permission rules in .claude/settings.json, MCP servers from ~/.claude.json, and hooks from Claude’s settings. /import-claude copies permissions, environment variables, MCP servers, hooks, and paths into Grok’s own config.

Claude’s auto-memory is a different folder: ~/.claude/projects/…/memory/MEMORY.md. Grok leaves that folder alone. /memory inside Claude edits CLAUDE.md and that auto-memory. /memory inside Grok is Grok’s own notes under ~/.grok/memory.

Slash commands

Type / for the full list.

/plan
Think the change through before editing. Shift+Tab cycles Normal, Plan, Auto, Always-approve.
/always-approve
Skip ordinary permission prompts. /auto lets a classifier approve safe calls and still ask about the rest.
/compact
Shrink the conversation so the window does not fill up. /context shows what is using it.
/model
Switch model. /effort sets reasoning to low, medium, high, or xhigh.
/resume
Open an earlier session. /new starts a fresh one.
/rewind
Roll the conversation back to an earlier turn.
/remember
Save a note now. /flush writes what this session learned. /dream tidies notes. /memory browses them.
/import-claude
Copy Claude settings into Grok. Separate from the files Grok already reads.
/copy
Copy the last reply. /btw asks a side question without derailing the task.

Claude Code

The deck starts it with --remote-control and the session name, so the same session shows up in the Claude phone app.

CLAUDE.md is the file Grok also reads. Auto-memory notes under ~/.claude/projects/…/memory/ stay with Claude.

Slash commands

/init
Write a starter CLAUDE.md for this repo.
/memory
Edit CLAUDE.md and the auto-memory notes.
/plan
Plan before a large change. /model and /effort change model and reasoning.
/compact
Summarize the conversation. /context shows what is loaded. /clear starts fresh and keeps project memory.
/permissions
Allow, ask, or deny tool rules for this session.
/remote-control
Already on for sessions started from the deck. Alias /rc.
/rewind
Roll code and conversation back to a checkpoint.
/resume
Return to an earlier conversation.
/mcp
MCP servers. /diff shows the change.

Codex

OpenAI’s terminal agent. /init writes AGENTS.md, which Grok also loads when that file is in the repo.

Slash commands

/model
Model and reasoning effort for this chat.
/approvals
What Codex may do without asking.
/plan
Plan mode for a multi-step change.
/compact
Summarize the conversation to free the window.
/review
Review the working tree. /diff shows the git diff, including untracked files.
/init
Scaffold AGENTS.md in this directory.
/status
Model, context usage, and rate limits.
/new
Fresh chat in the same repo. /resume opens an older one.
/mcp
List configured MCP tools.

OpenCode

The model list in the create dialog is read from your OpenCode config (~/.config/opencode/opencode.json[c]): every provider and model you have defined there.

Slash commands

/models
Pick a model. Ctrl+X then M does the same.
/new
New session. Alias /clear. Ctrl+X then N.
/sessions
Switch session. Aliases /resume and /continue.
/compact
Summarize this session. Alias /summarize.
/undo
Revert the last turn and its file changes. /redo puts them back. Both need a git repo.
/init
Create or update AGENTS.md.
/connect
Add a provider and its key.
/btw
Side question. The answer is not added to the conversation.
/share
Public link to this session. /unshare takes it down.

Shell

A plain shell in the project directory. No agent, so there are no slash commands.

From an agent card, Empty shell (or sh while you are attached) opens a shell in that session’s directory. If the agent is waiting on a permission question, the command is copied into the compose box. It runs when you send it.

Antigravity

Google’s replacement for Gemini CLI. The ＋ menu starts it as Antigravity, which runs agy in the project directory.

agy --continue resumes the last conversation. agy remote-control keeps the machine reachable from another device. Inside a session, type / for its commands. /copy copies the last response.

agy update brings the binary up to the current release. antigravity-ide on the PATH is the separate desktop app.
